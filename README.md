## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- Node.js 16+\n- npm 7+

### نصب

```bash
git clone https://github.com/tetrashop/tetrashop-production.git
cd tetrashop-production
npm install
```

### اجرا

```bash
npm run dev
```
